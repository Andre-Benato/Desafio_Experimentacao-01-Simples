# Desafio 01 — Calculadora de desconto

**Linguagem:** Java

## Objetivo

Desenvolver uma solução em Java para calcular o preço final de um produto após a aplicação de um desconto percentual.

A solução deverá ser implementada em uma classe chamada `CalculadoraDesconto`, responsável por realizar o cálculo e retornar o preço final.

O projeto deverá compilar e permitir a execução de testes automatizados.

## Método esperado

```java
public static double calcularPrecoFinal(
    double precoOriginal,
    double percentualDesconto
)
```

## Orientações

- Implemente a solução no projeto existente.
- Respeite o nome da classe e a assinatura do método.
- Utilize Java.
- Não implemente interface gráfica ou entrada de dados pelo console.
